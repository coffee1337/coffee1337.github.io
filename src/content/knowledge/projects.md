# Projects

## RU
ai-python-mentor — full-stack платформа для обучения Python и бэкенду: Next.js, FastAPI, AI Gateway, LLM, RAG на pgvector, PostgreSQL, Redis, Telegram-бот.
ngieuapp — кроссплатформенное приложение университета: расписание, офлайн-кэш на SQLite, уведомления и виджеты. Flutter, Dart, Riverpod, Drift.
TransactionMonitor — десктопное приложение для мониторинга транзакций и оценки риска. C#, .NET 8, WinUI 3, SQL Server.
neural-astar-heuristic — нейросетевая эвристика для A*: сначала решённые состояния, затем обучение функции ценности, затем поиск. Python, PyTorch, NumPy.
k-nearest-neighbors — классификатор k-NN с нуля на C++17 с десктопной визуализацией: евклидово, манхэттенское и косинусное расстояние, взвешенное голосование, нормализация.
portfolio-analytics — собственная аналитика сайта: клиентский beacon на fetch keepalive/sendBeacon с очередью ретраев и точным активным временем, коллектор на FastAPI, SQLAlchemy 2.0 и PostgreSQL (Neon; локально SQLite), SPA-дашборд на React 19 + TypeScript + Tailwind CSS и Docker. Стек: Python, FastAPI, PostgreSQL, SQLAlchemy, SQLite, React, TypeScript, Tailwind CSS, Docker. Возможности: воронка секций, матрица активности 24×7, весовой интерес к проектам, журнал вопросов AI-ассистенту и команд Cmd+K, Core Web Vitals (LCP, INP, CLS, TTFB), приватность — маска подсети и солёный HMAC вместо сырых IP.

## EN
ai-python-mentor — a full-stack platform for learning Python and backend development: Next.js, FastAPI, AI Gateway, LLM, RAG on pgvector, PostgreSQL, Redis, Telegram bot.
ngieuapp — a cross-platform university app: schedule, offline SQLite cache, notifications and widgets. Flutter, Dart, Riverpod, Drift.
TransactionMonitor — a desktop app for transaction monitoring and risk analysis. C#, .NET 8, WinUI 3, SQL Server.
neural-astar-heuristic — a neural heuristic for A*: solve states first, learn a value function, then search. Python, PyTorch, NumPy.
k-nearest-neighbors — a k-NN classifier written from scratch in C++17 with desktop visualisation: Euclidean, Manhattan and cosine distance, weighted voting, normalisation.
portfolio-analytics — first-party analytics for this site: a client beacon on fetch keepalive/sendBeacon with a retry queue and accurate active time, a FastAPI collector, SQLAlchemy 2.0 with PostgreSQL (Neon; SQLite locally), a React 19 + TypeScript + Tailwind CSS SPA dashboard and Docker. Stack: Python, FastAPI, PostgreSQL, SQLAlchemy, SQLite, React, TypeScript, Tailwind CSS, Docker. Features: section funnel, 24×7 activity matrix, weighted project interest, a log of AI-assistant questions and Cmd+K commands, Core Web Vitals (LCP, INP, CLS, TTFB), privacy via subnet masking and a salted HMAC instead of raw IPs.
