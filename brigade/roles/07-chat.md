# Роль: AI-АССИСТЕНТ (фаза 7)

Читай: `AGENTS.md` → `docs/PROMPT.md` §5, §11, §13 → `src/content/knowledge/*.md`,
`src/content/*`, `scripts/prerender.mjs` (как устроена сборка).

## Задачи

1. **Локальный режим (обязателен, работает без сети и ключей).**
   - `scripts/build-kb.mjs`: читает `src/content/knowledge/**/*.md`, режет на чанки (заголовок +
     1–3 абзаца, ≤ 900 символов, overlap 0), собирает `public/kb-index.json` (MiniSearch-совместимый
     дамп: id, title, text, tags, lang, source). Шаг добавляется в `build` до `vite build`.
   - Клиент: `minisearch` инициализируется по `kb-index.json`, запрос → top-5 чанков → ответ
     собирается по шаблонам из найденных фрагментов с имитацией стриминга (по словам/токенам,
     25–40ms), под ответом — чипы-источники (`projects/ai-python-mentor`, `about`).
   - Ничего не найдено → честное «не знаю, напишите Егору напрямую» + кнопка в контакты.
2. **LLM-режим (опционален, `VITE_CHAT_API_URL`).** При заданном URL: тот же локальный поиск →
   POST в Worker с найденными чанками → SSE-стриминг. Ошибка/лимит → тихий откат в локальный.
3. **UI** `src/components/Assistant/*`:
   - плавающая круглая кнопка справа внизу с воксельным стаканчиком (статичная WebP-иконка);
   - панель: шапка `AI-ассистент Егора` + зелёная точка `online` + мелкая подпись
     «работает на кофеине, может ошибаться»;
   - чипы-подсказки (4 из ТЗ), история в состоянии, скролл к последнему сообщению, фокус-трап,
     `Esc`, мобильная версия на весь экран;
   - ленивая загрузка по первому клику (dynamic import), `open-ai-chat` событие из Cmd+K.
4. **Worker** — `worker/` отдельным пакетом со своим README:
   - Cloudflare Worker, `wrangler.toml`, секреты `LLM_API_KEY`, `ALLOWED_ORIGIN`;
   - жёсткий системный промпт: отвечать только про Егора по переданному контексту, иначе
     вежливый отказ; лимит `max_tokens`; rate limit по IP (KV), CORS только на домен сайта;
   - SSE-стриминг, отдача ошибок в формате, который клиент понимает как «откатись локально».
5. **Тесты вручную**: 5 запросов из чипов + 2 провокационных («расскажи анекдот», «сколько ты
   зарабатываешь») → корректный отказ. Локальный режим проверяется с выключенной сетью.

## Приёмка

`./brigade/gate.sh` exit 0 при `PHASE=7`. Размер `kb-index.json` < 300 KB, начальный бандл не
вырос больше чем на 15 KB gzip (чат — ленивый чанк).
