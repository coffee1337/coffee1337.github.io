## Задачи

1. **§01 «С чем вы пришли» (§4.2).** Новый компонент `src/components/Entry/Entry.tsx`: три карточки
   в ряд (мобильные — столбик), острые углы, при наведении терракотовая полоса слева и `↗`.
   Действия: найм → скачать резюме + `#about`; фриланс → `#contact` с предзаполненной темой
   «Проект» (через контекст формы); код → `#projects` + GitHub.
2. **§02 About + образование (§4.3).** Философия слева, карточка EDUCATION справа (моно-лейблы,
   бейдж `3RD YEAR` пиксельным шрифтом, чипы дисциплин). Образование — база под ML/AI, не главный акцент.
3. **§04 Projects (§4.5).** Заменить текущий `Projects.tsx` на три части:
   - **фильтры-пилюли** по технологиям: `All · Python · AI/ML · FastAPI · Flutter · C# · C++`;
   - **дерево-проводник** `src/components/Projects/Explorer.tsx`: `role="tree"`, `role="treeitem"`,
     `aria-expanded`, клавиатура ↑↓←→ Enter, фокус-ринг, группы `ai/ mobile/ desktop/ ml-from-scratch/ tools/`,
     иконки-глифы по языку, активный файл с терракотовой полосой, над деревом «вкладка» с именем файла;
     фильтр приглушает неподходящие файлы, не удаляет;
   - **карточка проекта**: SVG-схема (компоненты из фазы 6; до неё — текущий `ProjectVisual`),
     название, описание, теги, кнопки `GitHub ↗` / `Case study →`, CLI-блок
     `$ git clone https://github.com/coffee1337/<repo>` с копированием, кнопка `Details` →
     аккордеон PROBLEM / SOLUTION / RESULT (без выдуманных цифр);
   - смена проекта — crossfade (framer-motion), URL-хэш `#projects/<id>` обновляется и читается
     при загрузке (шаринг ссылки);
   - мобильные: дерево → горизонтальный скролл пилюль, карточки столбиком.
4. **Порядок секций в `App.tsx`**: §00 Hero → §01 Entry → §02 About+Education → §03 Stack (пока
   текущий, клавиатура будет в фазе 6) → §04 Projects → §05 Reviews → §06 Contact → Footer.
   У каждой секции — моно-лейбл `§0N / NAME` слева и гигантский полупрозрачный номер (outline,
   opacity 0.06) справа, тонкие линии `--line` как разделители.
5. **Аналитика.** Сохрани существующие вызовы `portfolio-analytics` там, где они были; новые
   секции получают `data-section` атрибут для beacon'а.
6. **a11y**: у аккордеона `aria-expanded`/`aria-controls`, у дерева полный набор, у фильтров —
   `aria-pressed`. Фокус-ринг терракотовый 2px.
