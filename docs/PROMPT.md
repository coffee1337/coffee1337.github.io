* **GSAP + ScrollTrigger + Lenis** — анимации при скролле (оставить текущую систему `data-reveal`, но исправить баг из раздела 10).

## 3\. Глобальные компоненты

### 3.1 `<ScrambleHeading>` — расшифровка заголовков

* Применять **только к заголовкам секций** (h2) и к заголовку hero. Не к кнопкам, ссылкам и тексту.
* Срабатывает один раз при входе в зону видимости (порог 0.4).
* Символы перебираются из набора `#/8}\~%\*01<>\_\[]=+` каждые \~35ms; буквы фиксируются слева направо со смещением \~25ms на символ; общая длительность 600–900ms.
* Без сдвига вёрстки: финальный текст рендерится невидимым и задаёт размеры, анимированный слой лежит поверх (`aria-hidden`), у заголовка правильный `aria-label`/текст для скринридеров и пререндера.
* В пререндеренном HTML сразу финальный текст. Анимация — прогрессивное улучшение.
* Работает и для кириллицы (набор символов тот же, без кириллических букв).

### 3.2 Шапка-«пилюля» (как dnbbch)

* **Мобильная версия:** пилюля с логотипом, `⌘` и `MENU` → открывает **текущее полноэкранное меню** с нумерацией `01…07` (сохранить и привести к новой стилистике).

### 3.3 Палитра команд Cmd+K (`cmdk`)

* Открытие: `Ctrl/⌘ + K`, кнопка в шапке, пункт в мобильном меню. `Esc` закрывает.
* Группы:

  * **Навигация** — секции;
  * **Проекты** — открыть карточку или страницу кейса;
  * **Действия** — скачать резюме, скопировать email, открыть GitHub/LinkedIn/Telegram, «Спросить AI-ассистента», «Написать мне»;
  * **Настройки** — тема, язык.
* Fuzzy-поиск по RU и EN синонимам. Футер палитры с подсказками `↑↓ навигация · ↵ открыть · esc закрыть` (моно, пиксельный шрифт для клавиш).
* Стиль: модалка по центру, blur фона, острые углы, строка ввода моноширинная с префиксом `>`.

### 3.4 Сплэш-экран (3 секунды) — «Загрузка модели»

Заменить текущий сплэш. Глобус не используем: тема — нейросеть и LLM.

Сценарий (\~3000ms):

1. **0–900ms.** Из хаоса случайных ASCII-символов на canvas собирается **схема нейросети**: 4–5 слоёв узлов (узел = символ `◉`/`●`/`0`/`1`, связи — точечные линии из `·`). Слева вверху моно-лог печатается построчно:
`> loading weights … shard 1/3 ✓` → `shard 2/3 ✓` → `shard 3/3 ✓` → `> tokenizer ready` → `> context: egor\_trefilov.md (4 096 tokens)`.
2. **900–2000ms.** По сети слева направо бегут **импульсы активации** (терракотовые вспышки, узлы подсвечиваются по слоям — forward pass). Внизу прогресс-бар из `▓░` с процентами.
3. **2000–2700ms.** Под сетью **по токенам стримится** имя: `Egor` · ` Tref` · `ilov` (RU: `Е` · `гор` · ` Треф` · `илов`), у каждого токена мелкая серая вероятность `p=0.97`. Затем `Python Backend \& AI`.
4. **2700–3000ms.** Узлы сети разлетаются и **превращаются в облако точек hero** (Embedding Space, см. 4.1) — бесшовный переход. Сплэш растворяется.

Правила:

* Полная версия — при первом визите за сессию (`sessionStorage`); при повторных переходах в той же сессии — короткая (\~700ms) или без сплэша.
* Пропуск: клик, любая клавиша, кнопка `skip ↵` в углу.
* Контент страницы есть в HTML под оверлеем (SEO и пререндер не страдают). Без JS оверлея нет.
* `prefers-reduced-motion` → статичный кадр 600ms.

## 5\. AI-ассистент «спроси обо мне» (бесплатно)

* Ответ стримится по токенам, под ответом — **чипы-источники** (`projects/ai-python-mentor`, `about`). Это прямая демонстрация RAG.

**Архитектура в два уровня (по умолчанию стоимость 0):**

1. **Локальный режим (всегда работает, без сервера и ключей):** база знаний `src/content/knowledge/\*.md` (о себе, стек, каждый проект, образование, контакты, FAQ по найму и фрилансу, RU+EN). Индекс **MiniSearch** собирается на этапе сборки → `public/kb-index.json`. Запрос → top-k чанков → ответ собирается из найденных фрагментов по шаблонам (с имитацией стриминга) + источники. Если ничего не найдено — честное «не знаю, напишите Егору напрямую» и кнопка в контакты.
2. **LLM-режим (опционально, если задан `VITE\_CHAT\_API\_URL`):** запрос + найденные локально чанки отправляются в **Cloudflare Worker** (бесплатный тариф). Worker вызывает LLM с бесплатным тарифом (например, Gemini API или Groq). Ключ — только в секрете Worker.

   * В Worker: жёсткий системный промпт («отвечай только про Егора по контексту, иначе вежливо откажись»), лимит токенов ответа, rate limit по IP (KV или Durable Object), CORS только на домен сайта, стриминг SSE.
   * При ошибке или превышении лимита — тихий откат в локальный режим.
   * Положи код Worker в `/worker` с README по деплою (`wrangler deploy`).
* Пункт «Спросить AI» в Cmd+K. Чат лениво грузится по первому клику.
