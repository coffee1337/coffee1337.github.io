# AGENTS.md — правила для любого агента в этом репозитории

Ты работаешь над редизайном портфолио coffee1337. Полное ТЗ — `docs/PROMPT.md`. Читай его
целиком перед первой правкой: это источник истины, а не этот файл.

## Что это

React 19 + TypeScript + Vite 7, Tailwind 3.4 + `src/styles/tokens.css`, GSAP 3 + ScrollTrigger,
Lenis, Three.js. Собственный пререндер: `scripts/prerender.mjs` + `src/prerender/entry.tsx`
(генерит `/`, `/ru/`, `/projects/:id/`, `/ru/projects/:id/`, sitemap, 404). i18n через URL,
тёмная/светлая тема с clip-path переходом, аналитика `portfolio-analytics`, деплой GitHub Pages.

Базовый билд (до редизайна) зелёный. Твоя работа не имеет права его сломать.

## Инварианты — нарушение = откат фазы

1. `npm run build` зелёный после КАЖДОГО коммита. Он включает `tsc -b`, `vite build`, SSR-сборку
   и `scripts/prerender.mjs`. Если билд красный — ты не закончил.
2. Пререндер не теряет текст. В `dist/index.html` и `dist/ru/index.html` должен быть весь
   контент: заголовки, секции, проекты. Проверка: `./brigade/gate.sh`.
3. Роутинг RU/EN, страницы проектов, 404, sitemap, скачивание резюме, переключение темы,
   аналитика — работают как до тебя.
4. Никаких захардкоженных строк в компонентах. Весь текст — в `src/content/{en,ru}.ts`,
   отзывы — `src/content/testimonials.ts`, база знаний — `src/content/knowledge/*.md`.
   Паритет ключей RU/EN обязателен.
5. Не выдумывать факты, цифры, компании, клиентов, метрики проектов. Данные о проектах —
   только из `src/content/*.ts` и README репозиториев `coffee1337/*`.
6. Новые зависимости — только из списка, разрешённого ТЗ: `framer-motion`, `cmdk`, `minisearch`,
   `@fontsource-variable/*`. Всё остальное — стоп и вопрос оркестратору.
7. Никакого `any` без причины, никакого `@ts-ignore` и `eslint-disable` для обхода ошибок.
8. Секреты только в `.env` / секретах репозитория. В коде — `import.meta.env.VITE_*`.

## Стиль кода

- Функциональные компоненты, хуки, `type` для пропсов, `interface` для публичных API.
- Файлы компонентов — `PascalCase.tsx` в `src/components/<Feature>/`; утилиты — `camelCase.ts`
  в `src/lib/`.
- CSS-переменные из `tokens.css` — единственный источник цвета. Никаких hex в компонентах,
  кроме случая, когда значение приходит из canvas/WebGL и читается через
  `getComputedStyle(document.documentElement).getPropertyValue('--accent')`.
- Анимации: Framer Motion — состояния UI; GSAP + ScrollTrigger + Lenis — скролл. Не смешивать
  на одном элементе.
- Каждый WebGL/canvas-компонент: `IntersectionObserver` (пауза вне экрана),
  `visibilitychange` (пауза в скрытой вкладке), `devicePixelRatio` ≤ 2, на мобильных меньше
  частиц, `prefers-reduced-motion` → статичный кадр.
- Всё, что зависит от браузера (часы, canvas, случайные числа), рендерится после гидрации;
  в пререндере — плейсхолдер (`--:--:--`), иначе расхождение гидрации.

## Доступность — не опция

- Видимый фокус: `outline: 2px solid var(--accent)`, offset 2px.
- `role="tree"` + клавиатура (↑↓←→ Enter) у проводника проектов; `aria-*` у карусели,
  аккордеонов, переключателей, тостов.
- Focus trap в модалках (Cmd+K, мобильное меню, чат), `Esc` закрывает.
- Контраст AA в обеих темах. Акцент — не для мелкого основного текста.

## Рабочий цикл

1. Прочитай `docs/PROMPT.md`, свой мандат в `brigade/roles/` и текущий код, который трогаешь.
2. Работай маленькими шагами: одна логическая правка → `npm run build` → проверка.
3. Перед коммитом: `./brigade/gate.sh` должен дать exit 0.
4. Коммит: `git add -A && git commit -m "<phase>: <что сделано>"`. Одна фаза — один-два коммита.
5. В конце — отчёт по шаблону ниже.

## Отчёт (обязателен, пишется в `brigade/logs/<role>.report.md`)

```
## Итог: <сделано / частично / заблокировано>
Коммиты: <sha> <сообщение>
Зелено: <что проверено командой и её вывод>
Частично: <что сделано не до конца и почему>
Не сделано: <что осталось, с конкретным следующим шагом>
Открытые вопросы к оркестратору: <или "нет">
```

Правило: `сделано` без прошедшего `./brigade/gate.sh` — ложь. Билд красный = `частично`.
